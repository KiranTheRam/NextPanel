# NextPanel icon

The icon uses two abstract comic pages on a purple background, with a green checkmark speech bubble overlapping the right page.

The selected 1254 × 1254 image was created with the built-in image generator and is retained as `nextpanel-icon-source.png`. Public assets provide 512-pixel app icons, 192- and 512-pixel PWA icons, a 180-pixel Apple touch icon, and a 32-pixel favicon. The maskable version centers a 350-pixel image on a 512-pixel background so the mark stays within the safe area. Versioned URLs allow browsers to pick up the new icon while the canonical filenames continue to serve the README and Unraid templates.
